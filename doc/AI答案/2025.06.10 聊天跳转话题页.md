## 讨论跳转

1. 找到讨论窗口右上方展开按钮组位置, 追加一行. "帖子图标+话题页+跳转图标".
2. 点击跳转 topics-detail 路由, 带过去消息 _id
```js
router.navigate({
    name: 'topics-detail',
    params: { id: topicId }, // 带过去消息_id
    search: { drid },
});
```
